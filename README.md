## About Me

I'm a software engineer who enjoys turning ideas into maintainable, user-focused software. My work spans backend development, mobile engineering, and practical AI integration—from designing APIs and data models to shipping mobile apps and connecting applications to intelligent services.

I care about more than making something work once. I aim to build software that is understandable, testable, secure, and ready to evolve as a product grows.

- **Backend engineering:** APIs, authentication, database design, integrations, and application logic.
- **Mobile engineering:** Flutter applications, state management, API integration, testing, and release workflows.
- **Applied AI:** LLM integrations, retrieval-augmented generation (RAG), embeddings, and agent-based workflows.
- **Delivery mindset:** I value clear communication, maintainable code, practical trade-offs, and shipping useful features.

I'm interested in collaborating with teams and clients who need a dependable engineer to build a product, improve an existing system, or turn a technical idea into a working solution.
